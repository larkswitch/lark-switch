# Security Policy

This project is unofficial and is not affiliated with ByteDance, Feishu, or Lark.

**Do not** open a public issue with tokens, App Secrets, OAuth URLs, raw auth logs, keychain dumps, or unreviewed diagnostic archives. Use `larkswitch doctor --share` (or `lpcctl doctor --share`) if you need a redacted report.

## Reporting a vulnerability

Use [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository. If that is not enabled yet, email the maintainer listed on the GitHub org profile.

## Supported versions

The public line is `0.2.x` during the initial open beta.
